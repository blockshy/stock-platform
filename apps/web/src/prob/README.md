# 概率预测页面

网页入口为 `/prob`，提供概率总览、个股详情、可靠性与复盘、回测以及任务与参数。统计计算由 Python 概率引擎完成，Java 后端负责接口和任务调度。

## 主要操作

- 在概率总览中按日期、周期、风险和股票筛选结果，进入个股详情查看分项与区间。
- 通过“公式说明”和指标旁的说明入口查看口径；任务与参数页面展示生效配置、特征注册表及模型信息。
- “一键运行日常任务”编排概率流程；“全市场预测”只执行预测阶段，不下载行情，也不代替量化评分或短期预测。
- 任务执行期间观察阶段、终止状态及最近成功查询时间。成功计数不是统一完成百分比，查询失败也不表示后台已经停止。

## 覆盖与结果边界

榜单只查询已经生成的预测，采集新行情不会自动生成预测结果。全站证券搜索范围可能大于引擎合格股票池；能搜索到股票不等于它在当前日期有预测。

当前个股概率范围以有效配置和资格检查为准，涉及前缀、历史长度、ST、停牌及缺失行情等条件。58 ETF 行情独立保存，不自动进入该模型。数量较少时先清空搜索和顶栏选股，再核对任务状态、日期、数量限制与数据覆盖。

LIVE、OOS、已结算和已排除记录用途不同，不能混为同一种评估样本。比较结果时保留基准日、周期、配置、模型版本及数据快照。迁移连接信息后还需核验模型版本和榜单选择行为。
