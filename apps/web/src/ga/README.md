# 遗传算法预测

网页入口为 `/ga`。本模块提供总览、预测复盘、错误分析、股票池管理、进化监控、因子检查、每日选股、后台任务、参数配置和数据清理。

## 使用顺序

1. 确认行情已准备，查看总览和后台任务中的实际状态。
2. 根据研究范围核对参数、周期与股票池，再提交相应计算任务。
3. 等任务结束后查看选股、预测复盘及个股详情；指标含义可从页面“指标说明”入口查看。
4. 修改参数或重新运行后，核对结果日期和任务记录，不将旧结果当成新结果。

## 配置与口径边界

- GA 参数由后端配置接口管理，前端展示当前生效值。不同周期、股票范围和验证状态的指标不能直接混合比较。
- 自动调度是否启用由实际后端配置决定；关闭自动触发不等于禁用页面手工任务。
- 预测、进化、晋升、回滚、参数保存及数据清理会写入数据库，应在明确目标环境后执行。
- 清理页面区分预览与执行。先查看影响范围和保留策略，再决定是否实际清理；不要把清理当作修复计算问题的默认手段。
- 数据规模、计算耗时和统计表现依赖数据与参数，本文不附带特定机器的历史运行结果。
