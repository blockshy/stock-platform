# 量化策略研究与回测

网页入口为 `/quant`，包含“策略与回测”“回测结果”“今日信号”和“任务历史”。模块通过 Java 后端执行策略、回测和事件研究，页面负责配置与结果展示。

## 主要功能

| 功能 | 用途 |
| --- | --- |
| 策略与回测 | 选择内置策略，配置区间、资金、仓位、成本、股票范围及策略参数 |
| 回测结果 | 查看绩效、净值、回撤、交易明细和事件研究 |
| 今日信号 | 查看当前行情快照下的策略扫描结果，支持筛选和导出 |
| 任务历史 | 查看已提交任务的状态、参数和结果 |

## 使用边界

- 开始前先检查行情覆盖和目标区间；策略预热窗口、缺失行情及股票范围会影响实际参与证券。
- 表单参数及约束以后端返回的定义为准。更换手续费、滑点、股票池或策略参数后，结果应作为不同实验比较。
- 回测任务提交后应观察真实状态。页面查询失败不代表任务终止，重新提交前先检查任务历史。
- 今日信号基于已加载的行情快照与策略配置，不能代替实时行情；更新数据后需核对展示日期及刷新状态。
- 分别查看样本内、样本外和全区间指标，并结合交易笔数判断样本覆盖。回测不保证未来表现。
- 耗时受股票数量、日期范围、缓存和服务器资源影响，不把特定机器的历史耗时当作性能承诺。
