# 股票研究平台后端

本模块为 Java 21 / Spring Boot API，负责行情采集、数据查询、量化评分、短期预测、策略研究和任务调度。前端通过 `/api` 使用服务，Python 概率引擎由后端直接启动子进程调用。

## 运行前提

当前统一部署面向 Windows，需准备 JDK 21、Maven、独立 MySQL 实例、应用凭据以及 Python 引擎虚拟环境。后端与引擎必须能访问各自配置的文件和运行目录；概率引擎不是另一个已经部署的 HTTP 服务。

数据库、行情、模型和本机配置不随 Git 分发。首次使用前按[配置说明](../../docs/configuration.md)准备环境；根目录命令并不是数据库安装器。

在项目根目录运行统一入口：

```powershell
# 核对本地依赖及配置，不启动采集或模型任务。
npm.cmd run check

# 查看应用与任务状态。
npm.cmd run status

# 已完成配置和构建后，启动平台的数据库与应用。
npm.cmd start
```

统一启动器注入数据库连接、端口和 Python 路径，并加载本地运行配置。直接运行 JAR 或 `spring-boot:run` 不会自动获得这些配置；公共基础配置中的数据库地址、调度与初始化行为也可能与本地覆盖不同，因此不作为日常默认入口。

## 功能范围

| 功能 | 职责 |
| --- | --- |
| 行情与采集 | 查询证券、K 线、统计和历史采集任务 |
| 评分与短期预测 | 生成并查询对应评分、预测和历史结果 |
| 概率接口与调度 | 创建任务、启动 Python CLI、读取进度和概率结果 |
| 量化策略 | 策略回测、事件研究与信号扫描 |
| 遗传算法 | 预测、进化、参数和任务管理 |
| 做 T 研究 | 模拟交易、扫描和计划 |

58 ETF 使用独立行情口径，不自动进入个股评分和概率股票池。旧版额外预测服务与 `stock-fetch` 不属于当前工程。

## 测试与运行保护

完整离线验收从项目根目录执行 `npm.cmd test`，其中 Java 测试排除需要真实 Spring/数据库的集成类。不要将裸 `mvn test` 当作同等的无数据库检查入口。

真实集成验证必须使用独立验收库、账号、端口和模型目录，不能只换端口就启动第二个后端连接同一生产库。采集或计算中不重启服务、不覆盖正在使用的 JAR；停止和构建命令会核对任务及产物占用。

具体步骤见[测试与验收](../../docs/testing.md)，用户操作见[使用指南](../../docs/user-guide.md)。

## 公网部署状态

当前后端没有完整用户认证与权限控制，CORS 配置不是身份鉴权。采集、重算、参数保存、训练和清理等写接口不能直接作为公共 API 开放。后续部署需增加 HTTPS、访问认证、内部数据库网络及资源验证，详见[远端部署规划](../../docs/remote-deployment-plan.md)。

本次仅保留部署规划，没有交付 Linux 容器或远端自动部署脚本。
