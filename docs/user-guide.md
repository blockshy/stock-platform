# 使用指南

本文面向已经完成本地安装、数据库配置与构建的使用者。首次准备环境请先阅读[项目说明](../README.md)和[配置说明](configuration.md)。仓库不附带行情、数据库快照、已训练模型或个人连接配置。

## 启动与关闭

在 Windows PowerShell 中进入项目根目录后执行：

```powershell
# 查看受管进程和任务状态，确认没有重复运行的任务。
npm.cmd run status

# 启动已配置好的独立数据库和应用；此命令不负责首次安装依赖。
npm.cmd start

# 仅在任务空闲时停止应用；运行中的采集或计算会阻止停止操作。
npm.cmd stop
```

网页地址由当前配置的 `webPort` 决定，示例端口为 `http://127.0.0.1:5173`。本地启动器只监听回环地址；远端公网部署另见[部署规划](remote-deployment-plan.md)，目前不能直接将本机启动命令当作公网部署命令。

## 功能入口

| 页面 | 主要用途 | 使用前提 |
| --- | --- | --- |
| 市场看板、股票列表、股票详情 | 查看行情、筛选证券、查询 K 线与区间统计 | 对应行情已入库 |
| 数据抓取 | 创建历史行情采集任务、查看任务状态与覆盖范围 | 独立数据库可用，行情源可连接 |
| 量化评分 | 查看因子评分、排行与连续性，发起重新计算 | 对应时间窗口有足够有效行情 |
| 短期预测 | 查看持有周期预测和历史逐日预测 | 已采集行情并完成相应计算 |
| 概率预测 | 查看 LIVE 预测、样本外评估、风险指标与运行记录 | Python 引擎配置正确，数据与模型满足资格检查 |
| 策略回测、遗传算法预测 | 配置策略、运行实验、比较结果 | 对应数据和参数已准备 |
| 做 T 模型、做 T 模型 2 | 模拟交易、扫描与生成计划 | 对应股票行情已准备 |

旧版“模型预测”依赖额外预测服务，该服务没有随本工程集成；关闭旧功能开关时页面会给出不可用说明。`stock-fetch` 也不在当前工程范围内。

## 从采集到预测

1. 打开“数据抓取”，指定日期范围和证券范围。默认股票范围为 `00`、`30`、`60` 前缀；“最多证券数”为 `0` 表示不人为限制数量。交易所停牌、退市、源站缺失等情况可能影响实际覆盖。
2. 等待任务结束，检查成功、失败和覆盖范围。采集成功不代表评分或预测已经更新；失败证券也不会自动变成成功记录。
3. 到“量化评分”执行评分计算；到“短期预测”执行对应的预测生成操作。分别检查结果日期和完成状态。
4. 到“概率预测 → 任务与参数”运行概率任务。首次建立结果或需要更新整个流程时，使用“一键运行日常任务”；只需要使用现有数据和模型更新 LIVE 结果时，使用“全市场预测”。
5. 等概率任务终止并核对结果后，再查看榜单和股票详情。刷新网页或切换页面不会取消后台任务。

“一键运行日常任务”编排数据准备、滚动样本外评估、训练、预测、结算、评估复盘及回测。它不是行情下载按钮，也不代替独立的量化评分和短期预测任务；部分阶段会根据配置、已有结果和断点决定是否执行。

## 58 开头 ETF 的边界

在采集页面使用 `58` 前缀可采集该范围 ETF。ETF 行情单独保存，成交量以“份”为单位；股票和 ETF 的数据口径不能混用。

当前个股评分与概率模型的股票池不包含这批 ETF。采到 ETF 行情后，ETF 不会自动出现在个股概率榜单。扩大 ETF 模型支持需要另行定义训练样本、特征、交易规则和验收标准。

## 如何理解“全市场”和榜单数量

“全市场”表示处理当前配置与数据检查下符合资格的股票，并不表示包含交易所全部证券。历史长度不足、停牌、缺失比例、ST 排除规则及前缀配置都可能缩小股票池。

榜单是已有预测结果的查询，不会因为新行情入库而自动增加行数。数量较少时依次检查：

- 清空页面关键词和顶栏当前股票选择，核对日期、周期及其他筛选项。
- 查看最后一次预测任务是否成功结束，以及处理范围是否设了调试数量限制。
- 检查符合历史长度要求的股票数、失败记录和模型是否就绪。
- 核对结果的基准日与模型版本。跨环境迁移后，同日版本选择仍需要专门验收。

## 进度与结果的判断

页面的“最近成功查询”用于判断浏览器是否持续收到状态。状态查询失败表示网络或接口读取出现问题，不能据此认定计算已停止；训练阶段的成功数暂时为 `0` 也不等于卡住。

先保留任务编号，结合阶段说明、开始时间、结束状态和本地日志排查。不要反复点击运行按钮，也不要在任务执行中强制结束 Java 或 Python 进程。具体排查方法见[常见问题](troubleshooting.md)。

统计结果以页面展示的基准日、周期、模型版本和数据覆盖为准；历史概率与回测收益不能保证未来表现。
